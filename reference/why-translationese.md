# 왜 번역체가 나오는가

고치기 전에 원인을 알아야 재발을 막는다. 번역체는 어휘 문제가 아니라 **생성 절차**의 문제다.

## 근본 원인: 한국어가 파생물이다

영어 초안이나 영어식 개요를 먼저 만들고 한국어로 옮기면, 한국어 문장에 영어 통사
구조가 남기 쉽다. 단어는 한국어인데 문장 골격은 영어인 상태가 번역체다.

**교정 순서를 아무리 정교하게 짜도 이걸 못 이긴다.** 번역된 문장을 다듬으면 번역체가
매끄러운 번역체가 될 뿐이다. 절차를 바꿔야 한다.

## 언어 차이 — 어디서 어긋나는가

| | 영어 | 한국어 |
|---|---|---|
| 문장을 굴리는 축 | 명사 | 동사 |
| 수식의 방향 | 뒤로 뻗음 (관계절) | 앞으로 쌓임 (관형절) |
| 주어 | 필수, 무생물도 행위 가능 | 생략 가능, 행위자가 주어 |
| 주제/초점 표시 | 어순·강세 | 조사 (은/는 vs 이/가) |
| 서술어 위치 | 앞 | 끝 |

번역체 증상은 전부 이 표의 왼쪽을 오른쪽에 억지로 끼운 결과다.

### 1. 명사 쌓기 — 영어는 되고 한국어는 안 된다

영어는 명사구를 쌓아도 전치사가 관계를 표시해준다. 한국어는 조사로 표시하는데,
명사를 쌓으면 조사가 '의'·'에 대한'으로 뭉개진다.

```
X  Pydantic 모델을 통해 문자열을 숫자로 변환하는 등의 자동 보정을 수행하여 호출 성공률을 높입니다.
O  Pydantic 모델이 "123"을 123으로 바꾼다. 이런 자동 보정 덕에 호출 성공률이 올라간다.
```

`~을 통해`, `~에 대한`, `~의 수행`이 한 문장에 모이면 거의 확실히 번역이다.

### 2. 좌측 과적재 — 체감상 가장 큰 원인

한국어는 왼쪽에서 오른쪽으로 순차 처리되고, 뜻은 서술어에 닿아야 확정된다.
영어 관계절을 한국어 관형절로 옮기면 수식이 전부 앞으로 몰린다. 독자는 미결 상태를
오래 들고 있어야 하고, 그게 "읽어도 머리에 안 들어온다"의 정체다.

```
X  기존에 등록되어 있던 사용자가 소속되지 않은 워크스페이스에 접근하려 할 때 발생하는 권한 오류를 처리하는 핸들러
O  사용자가 소속되지 않은 워크스페이스에 접근하면 권한 오류가 난다. 이 핸들러가 그 오류를 처리한다.
```

수식이 길면 문장을 쪼갠다. 관형절은 하나까지다.

### 3. 무생물 주어

영어에서 `This PR fixes...`는 자연스럽다. 한국어에서 PR은 무언가를 하지 않는다.

```
X  이 PR은 세션 만료 시 토큰이 갱신되지 않는 문제를 해결한다.
O  세션이 만료되면 토큰이 갱신되지 않았다. 갱신 조건을 고쳤다.
```

두 번째가 더 짧고, 무엇이 잘못됐는지가 먼저 나온다.

### 4. 피동 남용

영어 수동태는 행위자를 숨기는 정상 도구다. 한국어에서는 대부분 불필요하고,
'되어지다'류는 이중피동이라 문법에도 어긋난다. <!-- lint-skip -->

```
X  이 값은 스케줄러에 의해 매 실행마다 갱신되어진다.
O  스케줄러가 매 실행마다 이 값을 갱신한다.
```

능동으로 뒤집을 때 행위자가 안 떠오르면, 문장이 아니라 설계 이해가 빈 것이다.

### 5. 주제/초점 붕괴 (은/는 vs 이/가)

영어에는 이 장치가 없어서 번역할 것이 없다. 그래서 번역체는 조사를 아무렇게나 쓰고,
문단 안에서 무엇이 이미 아는 정보이고 무엇이 새 정보인지 신호가 사라진다.

- `은/는` — 이미 무대에 올라온 것, 문단의 주제
- `이/가` — 처음 꺼내는 것, 새 정보, 초점

```
X  캐시가 무효화된다. 캐시가 워커에서 재생성된다.
O  캐시가 무효화된다. 이 캐시는 워커가 다시 만든다.
```

### 6. 빈 동사와 헤지

`수행한다`, `진행한다`, `제공한다`, `존재한다`는 영어 동사의 기본값 번역이다.
실제 동작을 쓰면 문장이 짧아지고 정확해진다.

```
X  검증을 수행한다 / 데이터가 존재한다 / 오류인 것으로 보인다
O  검증한다 / 데이터가 있다 / 오류다 (확인 못 했으면 "확인 못 했다"고 쓴다)
```

## 반대 방향도 있다 — 한국어를 옮긴 영어

한국어 우선으로 바꾸면 이번엔 영어가 한국어의 그림자가 된다. 흔한 증상:

- 명사화: `perform a validation` (한국어 '검증을 수행한다'의 직역) <!-- lint-skip -->
- 헤지: `it seems that`, `it is necessary to` (종결어미 '~인 것 같다', '~해야 한다')
- 수동: `is handled by the worker`
- `the fact that`, `in order to`, `and so on`

영어도 번역이 아니라 **다시 쓰기**여야 한다. 같은 사실을 영어 화자가 처음부터
쓴다면 어떻게 쓸지를 묻는다.
