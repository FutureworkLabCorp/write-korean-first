# 왜 번역체가 나오는가

고치기 전에 문장 구조가 어디서 왔는지 살핀다. 번역체는 어휘와 **작성 절차** 모두에서
생길 수 있다.

## 근본 원인: 한국어가 파생물이다

영어 초안이나 영어식 개요를 먼저 만들고 한국어로 옮기면, 한국어 문장에 영어 통사
구조가 남기 쉽다. 단어는 한국어인데 문장 골격은 영어인 상태가 번역체다.

문장별 직역이 문제라면 단어만 바꿔도 어순과 정보 배치는 남는다. 문단이 전하려는
사실을 확인하고 한국어 독자를 기준으로 다시 구성한다.

## 언어 차이 — 어디서 어긋나는가

| | 영어 | 한국어 |
|---|---|---|
| 자주 나타나는 표현 | 명사구와 전치사 | 조사와 서술어 |
| 수식의 방향 | 뒤로 뻗음 (관계절) | 앞으로 쌓임 (관형절) |
| 주어 | 대개 명시 | 문맥상 생략 가능 |
| 주제/초점 표시 | 어순·강세 | 조사 (은/는 vs 이/가) |
| 서술어 위치 | 주어 뒤 | 대개 문장 끝 |

이 표는 흔한 경향을 보여준다. 개별 표현이 번역체인지는 문맥에서 판단한다.

### 1. 명사 쌓기

영어는 명사구를 쌓아도 전치사가 관계를 표시해준다. 한국어는 조사로 표시하는데,
명사를 쌓으면 조사가 '의'·'에 대한'으로 뭉개진다.

```
X  Pydantic 모델을 통해 문자열을 숫자로 변환하는 등의 자동 보정을 수행하여 호출 성공률을 높입니다.
O  Pydantic 모델이 문자열을 숫자로 변환하는 등의 자동 보정을 한다. 이로써 호출 성공률이 높아진다.
```

`~을 통해`, `~에 대한`, `~의 수행`이 겹치면 관계를 풀어 쓸 수 있는지 검토한다.

### 2. 좌측 과적재 — 체감상 가장 큰 원인

영어 관계절을 한국어 관형절로 옮기면 수식이 앞에 몰리기도 한다. 수식 대상이
뒤늦게 나와 독자가 앞부분을 다시 읽어야 한다면 정보 순서를 고친다.

```
X  기존에 등록되어 있던 사용자가 소속되지 않은 워크스페이스에 접근하려 할 때 발생하는 권한 오류를 처리하는 핸들러
O  이미 등록된 사용자가 소속되지 않은 워크스페이스에 접근하려 하면 권한 오류가 난다. 이 핸들러가 그 오류를 처리한다.
```

수식이 길어 대상을 놓치면 문장을 쪼개거나 순서를 바꾼다.

### 3. 무생물 주어

영어의 `This PR fixes...`를 그대로 옮기면 행위보다 PR이 앞서기도 한다.
기술 문서에서 `이 PR은 ...` 자체가 잘못된 표현은 아니다.

"이 PR은 세션 만료 시 토큰이 갱신되지 않는 문제를 해결한다"는 자연스러운
요약이다. 문제와 조치를 분리해야 독자가 이해하기 쉬운 문맥이라면
"세션이 만료되면 토큰이 갱신되지 않았다. 갱신 조건을 고쳤다"처럼 쓸 수 있다.
둘 중 어느 쪽이 좋은지는 필요한 정보와 문서 목적에 달렸다.

### 4. 피동 남용

영어와 한국어 모두 피동을 쓸 이유가 있다. 다만 행위자를 이미 알고 있고 그가
중요한 문장에서 피동을 반복하면 장황해질 수 있다. `되어지다`류의 이중피동도
문맥에서 더 간결하게 쓸 수 있는지 살핀다.

```
X  이 값은 스케줄러에 의해 매 실행마다 갱신되어진다.
O  스케줄러가 매 실행마다 이 값을 갱신한다.
```

능동으로 바꿀 때 원문에 없는 행위자를 만들어 넣지 않는다.

### 5. 주제/초점 붕괴 (은/는 vs 이/가)

한국어 조사는 화제와 초점을 드러내기도 한다. 직역하면서 이 관계가 흐려졌는지 본다.

- `은/는` — 화제나 대조
- `이/가` — 주어 표시나 초점. 처음 등장할 때만 쓰는 조사는 아니다

```
X  캐시가 무효화된다. 캐시가 워커에서 재생성된다.
O  캐시가 무효화된다. 이 캐시는 워커가 다시 만든다.
```

### 6. 빈 동사와 헤지

`수행한다`, `진행한다`, `제공한다`, `존재한다`가 구체적인 동작을 가리면
그 동작을 직접 쓴다. 원문에서 이 단어가 실제 의미를 담으면 유지한다.

```
X  검증을 수행한다 / 데이터가 존재한다
O  검증한다 / 데이터가 있다
```

`오류인 것으로 보인다`처럼 추정 근거를 나타내는 말은 근거와 확신의 정도를
지킨다. 단정하거나 단순히 "확인하지 못했다"로 바꾸지 않는다.

## 반대 방향도 있다 — 한국어를 옮긴 영어

한국어 우선으로 바꾸면 이번엔 영어가 한국어의 그림자가 된다. 흔한 증상:

- 명사화: `perform a validation` (한국어 '검증을 수행한다'의 직역) <!-- lint-skip -->
- 헤지: `it seems that`, `it is necessary to` (종결어미 '~인 것 같다', '~해야 한다')
- 수동: `is handled by the worker`
- `the fact that`, `in order to`, `and so on`

영어도 번역이 아니라 **다시 쓰기**여야 한다. 같은 사실을 영어 화자가 처음부터
쓴다면 어떻게 쓸지를 묻는다.
